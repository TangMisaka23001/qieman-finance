## 使用

- 在 Muse 里直接提问即可，skill 会按主题自动匹配，例如问仓位、估值、再平衡、退休提款。
- 每个 skill 都要求先核对原文出处，个人参数（如 850 线、23% ETF 仓位）不作为普适参数。
